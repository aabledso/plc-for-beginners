# Reflection

## Decisions
I made the decision to use AI tools when planning the structure and Java for the mini-games and quizzes included on my site. Initially, I had planned on writing most of it myself, but I quickly realized that wasn't feasible with the amount of time I had available to dedicate towards working on my site.  

I also decided not to include a Contact page and to reduce the number of planned quizzes. I realized that neither of these would add value to my site.  

Another decision I made was to add a PLC animation to the hero on my site. In another course, we evaluated people's sites based on impressions in the first 10 seconds of viewing. I wanted people to be able to grasp the idea of a PLC even without having any knowledge about them, and I thought a visual would be a great way to accomplish this.


## What Worked
I would say the execution of my idea for a site that teaches people went well. My site breaks down various concepts of PLCs into easily understood chunks. The quizzes and games throughout each page also make the content less boring to consume. I am also proud of finsishing my project on time. After submitting P01, I realized how far my project still needed to go to even come to close to what I had planned for it. This realization drove me to commiting more time after work to finishing the site so I'd be able to submit it on time.


## Things I'd Do Differently
Next time, I won't use Visual Studio Code's Copilot feature. I used it early on into building my site (while I had free credits), and I feel like it made me lose control over my CSS. I usually organize my CSS using comments and structure it in the same order as my HTML. This makes it easier to change the styling of elements when necessary. After using Copilot, it inserted lengthy lines of code in both my HTML files and my CSS page. As my CSS file grew, I resorted to using Ctrl + F to find my elements.  

I also won't commit to creating mini games in my next project. There is nothing "mini" about the amount of Java that goes into creating interactive elements.

## What I Learned
Although typing Javascript was a very tedious task, it was a learning oppotunity. I learned about case-sensitivity, definining constants, and the implementation of if/else statements. Because Java is so picky about typos or things as simple as a lowercase letter instead of a capitalized letter, I learned how to use DevTools to troubleshoot.

While DevTools was useful for troubleshooting my script, it was also useful throughout my numerous attempts to implement media queries. I mainly used an open port in VS Code for seeing how my site displayed on desktop and then an iPhone SE 375x667 in DevTools to preview how my site looked on smaller screens.

Ladder Logic

Ladder Logic is a programming language used to develop software for PLCs. It is called "ladder" logic because the programs resemble a ladder with two vertical rails and a series of horizontal rungs between them.

How Does Ladder Logic Work?

Ladder logic is read from left to right and from top to bottom. Each rung represents a set of conditions that must be met before and output is activated.

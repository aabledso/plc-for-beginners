Ladder Logic Fundamentals

How Ladder Logic Works

Ladder logic is made up of horizontal lines called rungs. Each rung contains conditions that determine when an output is able to be energized.

The PLC evaluates each rung from left to right and them moves down to the next rung.

The Building Blocks

Know Your Instructions

Ladder logic uses different instructions to represent inputs, conditions, and outputs. Here are the ones you need to know.

-| |-

Normally Open

NO Contact

A normally open contact becomes true when its associated input is active.

Example: Start button

-|/|-

Normally Closed

NC Contact

A normally closed contact is true when its associated input is not active. When the associated input becomes active, the contact will become false.

Example: Stop button

-( )-

Output Coil

Output

An output coil turns on when all of the conditions before it on the rung are true.

Example: Motor

TON

On-Delay Timer

Timer

A TON timer begins counting when the conditions before it are true. After reaching its preset time, its done bit becomes true.

Example: TON 5 seconds

Putting Everything Together

Read a Rung

A ladder logic rung is read from left to right. The conditions on the left determine whether the output on the right will be energized.

Stop -|/|- NC
Start -| |- NO
Motor -( )- Output Coil

The PLC checks each instruction from left to right. If the Stop condition is safe and the Start button is pressed, the rung becomes true and the Motor output energizes.

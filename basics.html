PLC Basics

Programmable Logic Controllers (PLCs) are industrial digital computers that are used to control manufacturing processes, such as assembly lines, robotic devices, or any activity that requires high reliability and ease of programming.

How does a PLC work?

A PLC operates in a continuous cycle known as the scan cycle. During each scan, the PLC reads the status of all input devices, executes the user program, and updates the status of all output devices.

1

Input Scan

The PLC reads the status of all input devices, such as sensors and switches, and stores this information in memory.

→
2

CPU

The CPU processes the user program, making decisions based on the input data and updating the output devices accordingly.

→
3

Output Scan

The PLC updates the status of all output devices, such as actuators and lights, based on the results of the program execution.

Key PLC Components

  • CPU: The processor that executes the control program and manages communications.
  • Power Supply: Provides the DC power required by the PLC and modules.
  • I/O Modules: Interfaces for sensors (inputs) and actuators (outputs), available as digital or analog.
  • Communication Modules: Allow PLCs to connect to networks, HMIs, and other devices.
  • Programming Device: A PC or handheld unit used to write, upload, and debug the PLC program.

Common PLC Programming Languages

PLC programming is standardized by IEC 61131-3. The most common languages are:

  • Ladder Logic (LD): Graphical, resembling electrical relay logic — widely used for discrete control.
  • Function Block Diagram (FBD): Graphical blocks representing functions and data flow.
  • Structured Text (ST): High-level textual language similar to Pascal, suitable for complex algorithms.
  • Sequential Function Chart (SFC): Used for sequencing and state-based control.

Simple Start/Stop Motor Example (conceptual)

This example shows the idea behind a start/stop motor control using a start pushbutton, stop pushbutton, and a motor contactor coil (M).

START ---| |----+-------------------( ) M  ; latch motor on start
                |
STOP  ---|/|---+--/               ; break on stop

In ladder logic: a maintained motor output is latched by the start button and unlatched by the stop button.
